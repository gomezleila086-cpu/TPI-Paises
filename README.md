# Gestión de Datos de Países en Python

## Descripción

Este proyecto consiste en una aplicación desarrollada en Python para gestionar información sobre distintos países utilizando listas, diccionarios, funciones y archivos CSV.

## Funcionalidades

* Agregar un país.
* Actualizar población y superficie de un país.
* Buscar países por nombre.
* Filtrar países por continente.
* Filtrar países por rango de población.
* Filtrar países por rango de superficie.
* Ordenar países por nombre.
* Ordenar países por población.
* Ordenar países por superficie.
* Mostrar estadísticas generales sobre los países registrados.

## Requisitos

* Python 3.x

## Ejecución del programa

Ejecutar desde la terminal con el siguiente comando:

python main.py

## Archivos del proyecto

* main.py: contiene el código fuente principal.
* paises.csv: almacena la información de los países.
* README.md: documentación básica del proyecto.
